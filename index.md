# Balneabilidade Guia

## Guia documental / Documentation-only guide

[Português](#pt) · [English](#en) · [README no GitHub / README on GitHub](https://github.com/saipradikmallakuntla-tech/balneabilidade-guia/blob/main/README.md)

**Referência apenas / Reference only.** Sem qualidade atual da água ou liberação de banho. No current water quality or bathing clearance.

## PT

### Comece pela fonte, não por uma conclusão

Este guia ajuda a organizar a leitura de um boletim. Não substitui a CETESB, autoridades de saúde, sinalização ou orientações locais. Não reproduz resultados de análise, classificações de praias ou previsões ambientais. Não oferece filtros, calculadora ou dados em tempo real.

Ponto de partida oficial: [CETESB — Praias](https://cetesb.sp.gov.br/praias/). O link é uma referência institucional; este documento não confirma o conteúdo atual de uma página externa.

### Referências que precisam acompanhar a informação

| Campo | Pergunta de leitura | Limite |
| --- | --- | --- |
| Responsável e fonte original | Quem publicou e onde está o documento original? | Captura de tela ou resumo pode perder contexto |
| Praia e ponto de coleta | O local coincide com o ponto do seu interesse? | Um ponto não representa automaticamente a praia inteira |
| Data de amostragem | Quando a amostra foi coletada? | Não é necessariamente a data de publicação |
| Data de publicação | Quando o boletim foi divulgado? | Não prova condições no momento da visita |
| Classificação e observações | O que o documento realmente informa? | Este guia não emite classificação própria |
| Orientação local | Há placas, avisos ou instruções adicionais? | O guia não acompanha avisos atuais |

### Exemplo manual de datas — fictício

| Referência ilustrativa | Valor |
| --- | --- |
| Data informada para um documento fictício | 10/11/2026 |
| Data de uma visita fictícia | 17/11/2026 |
| Diferença entre datas civis | 7 dias |

Sete dias não são uma regra de validade. Mesmo zero dias de diferença não certifica segurança. Data recente, água aparentemente limpa ou ausência de um aviso neste site não autorizam concluir que o banho é adequado. Não há limiar de validade, pontuação de risco ou recomendação sanitária calculada aqui.

### Checklist antes de decidir

- [ ] Abrir o documento oficial, em vez de depender apenas de um resumo.
- [ ] Conferir responsável, praia e ponto de coleta.
- [ ] Distinguir data de coleta, data de publicação e data planejada da visita.
- [ ] Ler classificação, observações e orientações diretamente na fonte.
- [ ] Verificar placas e avisos locais, inclusive orientações relacionadas à chuva.
- [ ] Tratar informação ausente como desconhecida, nunca como autorização.

Concluir o checklist não libera o banho. Siga as autoridades responsáveis e orientações locais.

## EN

### Start with the source, not a conclusion

This guide organises questions to ask while reading a report. It does not replace CETESB, health authorities, signs or local guidance. It reproduces no test results, beach classifications or environmental forecasts and provides no interactive filters, calculator or live data.

Official starting point: [CETESB — Beaches](https://cetesb.sp.gov.br/praias/). This institutional link is a reference, not confirmation of a source website's current content.

| Field | Reading question | Limitation |
| --- | --- | --- |
| Responsible publisher and original source | Who published it and where is the original document? | Screenshots or summaries may omit context |
| Beach and sampling point | Does the location match the place of interest? | One point does not automatically represent an entire beach |
| Sampling date | When was the sample collected? | Not necessarily the publication date |
| Publication date | When was the report issued? | Not proof of conditions at the time of a visit |
| Classification and notes | What does the document actually say? | This guide issues no classification |
| Local guidance | Are there signs, notices or further instructions? | This guide does not track current notices |

### Fictional manual date example

| Illustrative reference | Value |
| --- | --- |
| Entered date for a fictional document | 10 Nov 2026 |
| Fictional visit date | 17 Nov 2026 |
| Calendar-day difference | 7 days |

Seven days is not a validity rule. Even a zero-day difference is not safety clearance. Recent dates, clear-looking water or no warning on this website do not establish suitability for bathing. No validity threshold, risk score or sanitary recommendation is calculated here.

### Decision-preparation checklist

- [ ] Open the official original rather than relying only on a summary.
- [ ] Match the responsible publisher, beach and sampling point.
- [ ] Distinguish sampling, publication and planned-visit dates.
- [ ] Read the classification, notes and instructions directly at the source.
- [ ] Check signs and local notices, including rain-related guidance.
- [ ] Treat missing information as unknown, never as permission.

Completing this checklist does not clear anyone to swim. Follow responsible authorities and local instructions.
